# Enterprise Governance Policy
Este pacote é destinado ao uso em ambientes críticos sob conformidade NIST/ISO27001.

## Regras de Execução
- Todos os logs de execução devem ser enviados para o SIEM centralizado.
- O uso de modelos externos é restrito e deve passar por auditoria mensal.
- O acesso a chaves de API é gerenciado via Vault corporativo.
