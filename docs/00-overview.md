# Neuroflux Product Suite
Este repositório contém os prompts e configurações para os 3 tiers do Neuroflux:
- **Starter**: Essencial para detecção básica e análise de logs.
- **Pro**: Para times de SOC que precisam de predição de ameaças e grafos de ataque.
- **Enterprise**: Solução completa com governança, conformidade e limites ilimitados.
